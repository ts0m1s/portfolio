Service icons from Dashboard Icons (https://github.com/homarr-labs/dashboard-icons),
the set used by Homarr and other homelab dashboards. Licensed under Apache-2.0.
Trademarks belong to their respective owners.

To add one: find the service at https://dashboardicons.com, download its SVG into this
folder, and set `icon` in src/config.ts to the file name without .svg. If the set also has a
`<name>-light.svg` version, download that too: it is used automatically in dark mode.
